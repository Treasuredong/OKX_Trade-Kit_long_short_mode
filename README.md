# OKX_Trade-Kit_long_short_mode
# Crypto老许的 AI 实盘策略 V4.1

这是一个面向 OKX USDT 永续合约的多标的 AI 自动交易策略，支持 `BTC / ETH / SOL / XRP / OKB / ORDI / TRUMP / DOGE / BNB / RAVE`。策略目标不是高频刷单，而是通过多维信号寻找更高赔率的波段机会，并自动完成挂单、止盈止损和持仓管理。

**核心能力**

- **无人值守执行**：每分钟自动扫描市场，发现符合条件的机会后自动执行，不需要手动触发。
- **多信号融合**：综合技术指标、资金费率、OI 持仓量、News 情绪、市场风险偏好、大户代理信号和多币种相关性进行判断。
- **OI 四象限判断**：结合价格与持仓量变化，识别新多头建仓、空头加仓、空头回补、多头止损出清等资金状态。
- **深度波段挂单**：默认不追市价，优先等待回踩或反抽，以限价委托获取更好的盈亏比。
- **强制风控**：每次开仓必须同时设置止盈和止损；缺少 TP/SL 时自动拒绝下单。
- **持仓后管理**：开仓后持续评估信号，必要时提前止盈、止损、减仓或补挂保护单。
- **仓位控制**：最多同时持有或挂单 `3` 个标的，同标的同方向有冷却期，禁止亏损加仓和多空混持。
- **可视化面板**：配套本地面板展示净值、盈亏、持仓、挂单、候选排名、News 情绪、OI 信号和无人值守状态。

**策略理念**

少做低质量交易，多等高赔率位置。V4.1 更偏向“波段机会捕捉 + 自动风控管理”，适合用于 AI Agent 自动交易和多信号量化策略研究。

**风险提示**

本策略仅用于技术研究，不构成投资建议。永续合约波动大且带杠杆，实盘使用需自行承担风险。
